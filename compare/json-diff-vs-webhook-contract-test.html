COMPARISON

JSON diff shows what changed. A consumer test checks what breaks.

Generic JSON diff

Useful for exact value and syntax changes. It normally does not explain decoder risk or produce a test for your handler.

Webhook drift scan

Classifies removed paths and type/shape changes as risk candidates, explains likely consumer impact, and produces a fixture test. It still cannot know your actual handler without code integration.

Use both

Use exact diff for audit detail and consumer tests for behavior. Neither replaces provider documentation.
